# Source verification package

Ethereum mainnet deployment is complete. These three compiler inputs were prepared locally from exact compiled metadata and sources. Every source passed its metadata Keccak-256 check. No wallet key, seed, witness or encrypted user backup is included.

On 22 November 2026, the project owner explicitly authorized publication of these contract sources to Sourcify, including its irrevocable public-display license. Verification results are recorded separately.

The inputs are listed with SHA-256 hashes in `manifest.json`. Original compilation settings are retained. The manifest records the actual pool library addresses; `deployment.json` and `pool-constructor-args.txt` contain public deployment parameters.
