The root [MIT license](LICENSE) records the existing `package.json` declaration for Hylsia's
otherwise unmarked project files. Files with their own SPDX headers, copyright notices, or licenses
retain those terms. This inventory does not relicense upstream code or assert that every bundled
distribution is MIT-only.

Other application and development dependencies are recorded with exact versions, download locations,
and integrity hashes in `package-lock.json`. Their own license files and notices remain applicable.
The table is a focused provenance inventory, not a complete distribution compliance assessment.

Groth16, Poseidon, Merkle trees, and privacy pools/association-set research are established work;
Hylsia does not claim to have invented them. Generated verifiers, common libraries and framework
code should not be presented as original cryptographic research. Hylsia's implementation changes
are reviewable in its actual source and commit history.

The `.gitattributes` classifications identify vendored and generated files for GitHub language
statistics. They do not remove files from the repository or establish how Zauth scores originality.
Preserve original headers when updating or regenerating a component. Reassess notices before
distributing an SDK or a new bundled release.
